- **Row kinds in data, keys in data.** The `lines` built-in declares `rowKinds` (`item`, `description`, `subtotal`, `percent`) with each kind's columns, labels and add key, `rowShortcuts: true` (core's fixed row keys) and `addOnSubmit: true` on the `rate` and `percent` columns (the last editable cell of an Item and of a Percent line; a Description line's cell is multiline, where Enter is a new line, and a Subtotal line has no input); all in `forms/hosts.ts` through `lib/invoice-lines.ts` (type-only imports: the generator loads hosts.ts in Node). A row's kind is its `kind` cell, set by the table; it is not a column.
- **Line cells.** Columns of the `lines` built-in (key · label · kind · component): `product` · Product or service · text · `LineProductCell`; `description` · Description · text (maxLength 4000) · `LineDescriptionCell`; `quantity` · Qty · number (min 0.01, max 1000000) · none (core `NumberInput`); `rate` · Rate · text · `LineRateCell` (the typed money text; cents are computed at write); `percent` · Percent · text · `LinePercentCell` (typed percent text; ppm at write); `amount` · Amount · number · `LineAmountCell` (display only: its value stays null, the server writes `amount`); `taxable` · Tax · toggle · none. Kinds: `item` {label `Item`, addLabel `Add line`, columns product, description, quantity, rate, amount, taxable, shortcut `Alt+Enter`}; `description` {label `Description`, addLabel `Description line`, columns description, span, shortcut `Alt+t`}; `subtotal` {label `Subtotal`, addLabel `Subtotal`, columns amount, span, shortcut `Alt+s`}; `percent` {label `Percent`, addLabel `Percent line`, columns product, description, percent, amount, taxable, `columnAt: { percent: 'rate' }`, shortcut `Alt+5`}. The wide grid's header is the first kind's columns (Product or service · Description · Qty · Rate · Amount · Tax · menu, as the spec); a column of another kind that is not in the first kind's list is drawn in the header slot `columnAt` names (a Percent line's percent cell sits under Rate, its Qty slot is empty). Required per kind: item → product; description → description; percent → product, percent.
- **Money and amount math** (`lib/document-lines.ts`, mirrored by Go `server/document_totals.go`, one vector file `server/testdata/document_totals.json` read by both test suites). Quantity is held as hundredths (`Math.round(qty * 100)`); `lineAmount(qty, rateCents)` = qtyHundredths × rate / 100 rounded half away from zero, computed in `BigInt` (TS) and `math/big` (Go), because 10^8 × 10^15 overflows 2^53 and int64. `percentAmount(ppm, baseCents)` = base × ppm / 1 000 000 rounded half away from zero, same integer math. A Subtotal line's amount is the sum of Item and Percent amounts since the previous Subtotal (or the first line). A Percent line whose line above is not an Item or a Subtotal has no amount and is listed in `percentTargetErrors`. Any line amount above `maxLineAmount` (10^15, `lib/money.ts`) sets `isTooLarge`. Taxable total = the sum of taxable Item and Percent amounts; tax per component is `taxOn(taxable, ppm)` (`lib/sales-tax.ts` / Go `taxOn`), called only after the taxable total is checked ≤ `maxStoredAmount` and each ppm is 0–1 000 000 (memory p2-tax-rates: Go `taxOn` panics on bad input). Total = subtotal + tax total.
