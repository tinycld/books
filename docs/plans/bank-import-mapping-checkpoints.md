- **E2E accounts (a deviation from spec §4 Tests, which says "on 1000 Business Checking").** `banking-page.spec.ts` asserts "1 file waiting" on 1000 Business Checking and `banking-keys.spec.ts` reads its file list, and the shared DB runs spec files on two workers, so an upload to 1000 by this spec breaks them while it is waiting.
