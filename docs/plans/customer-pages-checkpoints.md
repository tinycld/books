## E2E rules

- Every `test.describe` title starts with `customer-pages:`. Example: `test.describe('customer-pages: customer page', () => { … })`.
- `login` / `navigateToPackage` / `clickSidebarItem` from `@tinycld/core/e2e-helpers`; customer helpers from `tests/e2e/customer-form-helpers.ts` (`createCustomer`, `openCustomer`, `openCustomersList`, the `CUSTOMER_KIND` bindings). No raw PocketBase writes, no `page.goto` after login. Every test creates its own customer with a unique name (`uniqueName(...)` pattern of the customer specs).
- A load error is forced with `page.route('**/api/collections/<name>/records**', r => r.fulfill({ status: 400, … }))`, and the route is removed with `page.unrouteAll({ behavior: 'wait' })` before Retry.
- A test never posts a document dated before 2026-07-01.
- Find a row by its text: `locator.filter({ has: page.getByText(name, { exact: true }) })`.
- After a save that changes the route, wait for the new URL (`await page.waitForURL(/customers\/[a-z0-9]{15}/)`).
- Phone runs: navigate at the default viewport, then `page.setViewportSize({ width: 390, height: 844 })`.

E2E budget for the screen: 12 tests in all (checkpoint 2: 4, checkpoint 3: 3, checkpoint 4: 2, checkpoint 5: 3), all in `tests/e2e/customer-pages-*.spec.ts`. Edits to the p2-customers specs are not new tests.
